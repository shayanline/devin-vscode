# Support

## Extension help

Start with the [README troubleshooting guide](README.md#troubleshooting) and the [known issues](docs/known-issues.md). Search the [GitHub issue tracker](https://github.com/shayanline/devin-vscode/issues) before creating a report because an existing issue may already contain a workaround.

If the problem belongs to this extension, [open a GitHub issue](https://github.com/shayanline/devin-vscode/issues) and include:

- State the extension, VS Code, Devin CLI, and operating system versions.
- Describe what you expected and what happened.
- Provide the shortest sequence that reproduces the problem.
- Open **View: Toggle Output** in VS Code, select **Devin**, and include relevant messages.
- Add screenshots when they clarify the interface or error.

Remove credentials, access tokens, private code, personal information, and customer data from logs or screenshots before posting them publicly.

Feature requests also belong in the [GitHub issue tracker](https://github.com/shayanline/devin-vscode/issues). Explain the workflow you want to improve and the result you need rather than prescribing an implementation.

## Devin CLI and account help

Use the [Devin CLI documentation](https://docs.devin.ai/cli) for CLI installation, authentication, models, permissions, and configuration. Contact [Devin support](https://devin.ai/support) for Devin account, subscription, billing, or service problems.

## Security reports

Follow the [security policy](SECURITY.md) to report a vulnerability privately. Do not publish security details in an issue or Marketplace question.
